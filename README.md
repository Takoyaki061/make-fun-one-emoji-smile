Entry for the [One Emoji, One Smile](https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f) bounty on make.fun.

`main.py` writes exactly one emoji to `/output/entry.txt`:

> 🫶

Heart hands — a small, deliberate gesture of care offered to a stranger. It reads as warm at first glance, needs no context or shared joke, and feels picked for the moment rather than the default smiley: two hands shaping a heart, an offer rather than a reaction.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, deterministic.
